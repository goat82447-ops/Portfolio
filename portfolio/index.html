GenAI / Agentic AI

Exploring the future of software engineering

I work hands-on with AI coding assistants day to day — GitHub Copilot, Cursor, Gemini, and Anthropic's Claude — across writing, reviewing and debugging code. On the Dynamics 365 Omnichannel project I took that further, connecting LLMs with custom skills and plugins to build three automation agents, orchestrated through Azure with a markdown context file that persists memory/state across runs.

GitHub Copilot Cursor Gemini Claude (Anthropic)

Atlas Agent

Navigates the codebase and platform context during bug detection on the ACD platform — tracing an incident back to the relevant service, module, or recent change across the multi-GEO Dynamics 365 Omnichannel environment. Atlas narrows down where a defect actually lives before any fix is attempted, and helps surface the fix itself once the root cause is located, so engineering time goes into verifying the change rather than hunting for it.

Self-Heal Agent

Picks up where Atlas leaves off — proposing and applying fixes for detected issues, then feeding the change into the PR verification loop before it reaches a human reviewer. Built to close the loop between "here's the bug" and "here's a candidate fix ready for review," reducing the manual back-and-forth on routine, well-understood defects.

Tars Agent

Reviews pull requests directly — reading the diff against the platform's conventions, leaving comments, and approving or requesting changes as part of the PR verification workflow. Tars coordinates the routine task execution across the bug-fix and PR pipeline, so straightforward reviews move quickly and engineers can focus their attention on the changes that actually need it.
